# Raja Kasir — releases

Installers and update files for **Raja Kasir**, a point of sale for small shops.
This repository contains only compiled releases; the installed app reads its automatic updates from here.

Download the latest version under [Releases](../../releases/latest):

| OS | File |
|---|---|
| Windows 10/11 (64-bit) | `rajakasir-setup-<version>.exe` |
| Debian / Ubuntu | `rajakasir-<version>-amd64.deb` |
| Linux (any distro) | `rajakasir-<version>-x86_64.AppImage` |

Each installation needs a license key for its device — contact the seller with the device ID shown on first start.

Verify downloads with `SHA256SUMS.txt`.
